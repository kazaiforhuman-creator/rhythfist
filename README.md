# RhythFist｜コード試奏機

番号を並べるとバンドの音で鳴る、鼻歌のための伴奏機。

キー・コード進行（`4 5 3m 6m` のような番号）・BPM を選んで PLAY を押すと、ドラム・ベース・ギター（パワーコード）・和音が鳴ります。その上で鼻歌を歌って、メロディに合うコード進行を探すための道具です。

- 王道進行・小室進行・カノン進行などはボタン1つで切り替え
- ドラム（8ビート／疾走8ビート／2ビート／4つ打ち／静かめ）、ベース、ギターの弾き方を選べる
- 鍵盤で歌った音を探して、キーを決められる
- DAW に打ち込むためのメモ（コード名・ベースの音・パワーコードの3音）が出る

ブラウザだけで動きます（インストール不要）。音は PLAY を押してから鳴ります。スマホは消音モードだと鳴らないことがあります。
